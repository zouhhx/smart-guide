⚙️ 系统设置

🐾 豹小秘 mini · 基本配置

修改后点"保存并下发"会自动推送到所有在线豹小秘。唤醒词"小豹小豹"已固定在硬件烧录值中，不可修改。

🤖 大模型 (LLM) 配置

全局大模型设置 — 用于意图识别 LLM 兜底、AI 讲解词生成、问答兜底等所有 LLM 调用。
系统按 URL 路径自动识别协议: 含 /messages → Anthropic Messages 协议；其它 → OpenAI /chat/completions 兼容协议。
火山方舟 Anthropic 兼容: https://ark.cn-beijing.volces.com/api/coding/v1/messages
OpenAI 兼容 (Minimax/智谱等): https://<host>/v1/chat/completions
火山方舟 (Anthropic 协议) 常用: ark-code-latest； OpenAI 协议常用: minimax-m2.5、doubao-1-5-pro-32k-250115。 改动即时生效, 无需重启。

🧠 OpenClaw 决策桥

关闭后所有问答走 V5 原链路（意图识别 + 上方 LLM 兜底），不经过 OpenClaw。yaml 里 openclaw.enabled 仍为总开关。

🧭 智能参观规划 (Auto Plan)

开启后, 用户说 "为我定制参观" / "20分钟智慧城市" / 老访客泛化参观时, 系统用 LLM 动态编排路线; 失败自动回落到静态 tour_scripts. 查看运行日志: 运维面板.
