# Voice Gateway Web 管理端

## 启动

首次部署到Windows主机后，先双击`06-enable-lan-access.cmd`，在UAC窗口中允许管理员权限。该脚本会开放局域网访问所需的TCP 8765端口。

随后双击`05-web-manager.cmd`并保持该控制台窗口开启。程序会启动管理页面、自动启动语音服务，并在远程Windows主机上打开：

```text
http://127.0.0.1:8765/
```

局域网内的其他电脑可以使用以下任一种地址：

```text
http://远程Windows主机的计算机名:8765/
http://远程Windows主机的IPv4地址:8765/
```

例如远程主机IPv4地址为`192.168.1.50`时，访问
`http://192.168.1.50:8765/`。可以在远程主机运行`ipconfig`查看IPv4地址。

当前版本监听所有IPv4网卡，不设置登录密码。Windows防火墙规则允许本机各局域网子网中的设备访问，但不会主动向公网开放路由器端口。

## 推荐操作顺序

1. 双击`05-web-manager.cmd`，等待页面显示语音服务已自动启动。
2. 在“录音设备”中优先选择标记为`Windows WASAPI`的设备。
3. 调节Windows系统输入音量，并观察右侧实时麦克风输入电平柱。
4. 在“触发方式”中选择唤醒词模式或分贝触发模式。切换模式后点击“保存并应用”，语音子进程会自动加载新设置。
5. 唤醒词模式下，说出唤醒词并看到“唤醒成功，可以讲话”后提问；分贝触发模式下，输入电平连续达到设置阈值后会显示“声音已触发，可以讲话”。
6. 需要暂停监听时点击“停止语音”；再次点击“一键启动”才会恢复自动运行状态。

“保存并应用”会先校验、备份并原子保存配置。如果语音网关处于自动运行状态，管理端会只停止并重新启动`VoiceGateway-G10C-Test.exe`语音子进程，使新配置立即生效；Web管理端、浏览器和Windows主机都不会重启。自动重启期间，正在进行的一次语音识别可能被中断。如果用户此前明确点击了“停止语音”，则只保存配置并保持停止状态。

如果新配置导致语音子进程启动失败，管理端会恢复保存前的配置并尝试恢复原语音服务。恢复默认配置也采用相同的自动应用规则。

## 当前功能

- 一键启动和停止本地语音网关。
- 枚举PortAudio可见的Windows录音设备。
- 选择语音网关录音设备。
- 读取和修改Windows录音端点系统输入音量。
- 通过Windows Core Audio端点峰值表实时显示麦克风输入电平，不额外打开录音流。
- 修改中文唤醒词。
- 在唤醒词模式和免唤醒的分贝触发模式之间切换；两种模式共用原有VAD、ASR和中控文字接口。
- 分贝触发阈值可在`-60`到`-15 dBFS`之间调整；模式已经运行时可即时应用阈值，不重启服务或重新加载模型。
- 调节KWS `score`和`threshold`。
- 调节VAD结束静音时间。
- 配置校验、保存前备份、原子写入和恢复默认值。
- 在“最近识别”上方显示实时交互状态：等待唤醒、唤醒成功正在聆听、正在识别、问题已接收或服务未就绪。
- 查看进程状态、Pipeline状态、最近ASR结果和控制台日志。
- 本地ASR完成后，将识别文字异步发送到`http://192.168.16.61:3001/api/asr-text`，固定使用`target="2"`、`source="microphone"`，并展示返回JSON中的`reply`。
- KWS唤醒成功后，将命中的唤醒词异步发送到现有`/api/asr-text`接口，固定使用`target="2"`、`source="microphone"`；中控自行决定数字人的应答内容、动作或画面反馈，格式见`KWS-WAKE-NOTIFY-API.md`。
- 页面底部运行日志仅展示当前唤醒词、ASR识别结果和模型回答；完整诊断日志仍保存在本机日志文件中。
- 自动启动语音子进程，并在异常退出、启动超时、音频心跳超时或识别长时间无响应时进行有退避的恢复。
- 麦克风短暂断开或音频驱动异常后自动重新打开已选择的录音设备。
- Web管理进程异常退出后由`05-web-manager.cmd`延迟重启，连续失败时退避时间最高为60秒。
- 日志按日期或大小轮转，并限制保留时间和磁盘占用；配置备份数量同样有上限。
- 允许同一局域网中的其他电脑通过浏览器管理远程Windows主机。
- 状态、唤醒/聆听指示、最近识别结果和模型回答使用50毫秒高频轮询；请求防重入并在页面进入后台时自动降频。

## 自动恢复说明

- 关闭浏览器页面不会停止Web管理端或语音监听。
- 用户点击“停止语音”属于明确的人工停止，监督逻辑不会擅自重新启动语音。
- `VoiceGateway-G10C-Test.exe`异常退出时由Web管理端恢复；`VoiceGateway-WebUI.exe`异常退出时由`05-web-manager.cmd`恢复。
- `05-web-manager.cmd`只在第一次启动时打开浏览器，后续故障恢复不会不断创建新标签页。
- 如果TCP 8765已被另一个程序占用，启动器会停止并提示检查，不会高速循环启动。
- 不要同时运行`03-run-live.cmd`和`05-web-manager.cmd`，否则两个进程会争用同一录音设备。

当前发布包不会创建Windows Service、开机启动项或任务计划。Windows重启后仍需人工运行`05-web-manager.cmd`；若后续需要断电后来电自动恢复，应另行配置BIOS来电开机和“仅当专用用户登录时运行”的Windows任务计划。

## 说明和限制

- 当前仍使用本地SenseVoice INT8模型，不调用云端ASR。
- 局域网接口只接收KWS或ASR文字，不接收麦克风原始音频；接口断网、超时或返回错误不影响后续唤醒和本地识别。
- 当前Web管理端不是Windows Service，需要保持`05-web-manager.cmd`控制台开启。
- Windows系统音量依赖Core Audio端点映射。部分WDM-KS、蓝牙或特殊驱动设备可能只能录音，无法从网页控制系统音量。
- 修改系统输入音量会影响使用同一Windows录音端点的其他程序。
- 唤醒词当前限制为2到10个汉字。
- 分贝触发仅依据输入电平决定是否开始听取，不能判断声音是否来自主持人；阈值过低会增加环境谈话误触发，部署前必须按现场底噪和持麦距离实测。
- 当前不包含讯飞ASR；中控侧现阶段仅使用固定的`/api/asr-text`临时联调接口。
- Web管理接口未设置登录验证；只应在可信局域网中使用，不要在路由器上配置公网端口映射。
- 浏览器页面进入后台时会暂停50毫秒实时轮询，重新切回页面后立即恢复。

## 开发机重新构建

Web 源码位于项目根目录的 `webui/`。只调试源码时运行：

```powershell
.\scripts\run-web-manager-dev.ps1 -OpenBrowser
```

只调试页面或接口、不希望自动占用麦克风时运行：

```powershell
.\scripts\run-web-manager-dev.ps1 -OpenBrowser -NoAutoStart
```

重新生成包含语音核心和 Web 管理端的完整运行目录：

```powershell
.\scripts\build-test-package.ps1
```

生成正式 ZIP 和 manifest：

```powershell
.\scripts\build-release.ps1
```

不要直接修改 `artifacts/VoiceGateway-G10C-Test` 中的文件；该目录由构建脚本生成。
