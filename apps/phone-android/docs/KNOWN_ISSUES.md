# 当前已知问题与验收边界

## INT-001：按下麦克风偶发未停止播报

状态：待定位，未修复。用户已在 v1.7 真机观察到偶发失败，手机提示“停止播报结果未确认；可继续说话”，现场声音也未停。

当前手机实现：连接超时 2 秒、总超时 3 秒、无自动重试；部分 HTTP 错误、网络异常、响应校验失败使用同一提示。此信息不能单独判定故障属于手机、Wi-Fi、中控还是展示端。

建议下一位助手：

1. 获取测试手机 USB 调试授权，确认包名 com.codexpro.digitalhumanasr 和版本。
2. 收集 SpeechInterrupt 标签下的 requestId、target、结果及发生时间，关联 61 日志与展示端日志。
3. 当前手机日志未保存网络异常类型、HTTP 状态和响应耗时，必要时补充诊断，再复现；不要把潜在原因写成已证实根因。
4. 如采用短时重试，遵循 speech-interrupt-v15.md：同一次按下复用 target + requestId，不能在提交新问题后补发旧打断。
5. 验证正在播报、服务端慢回答、空闲、快速按下松手、取消、切屏等场景。

整合和上传源码不等于完成此问题修复。本次整理仅将凭据改为构建注入，不修改打断业务行为。
