## 新行为

按下麦克风时，使用当前屏号向配置的同一中控发送一次 POST /api/speech-interrupt，同时照常开始本地 ASR。松手后原 /api/asr-text 流程不等待打断成功；上滑取消不会提交新问题，但打断仍有效。每次按下使用新的 mic-press UUID，打断独立发送、总超时 3 秒、不自动重试。等待上一轮 HTTP 回答时可再次按下；旧回调被隔离。

## 现场验收

1. 选择已升级的 2 号屏，数字人播报中按下，确认不等松手即可停止。继续说新问题，松手后应正常回答。
2. 测试空闲按下、快速按下松手、上滑取消，以及上一轮回答尚未返回时再次按下。
3. 核对打断和本次问题均发向按下时的同一屏号；其他屏幕不受影响。
4. 按接口 v15 文档，完整能力限本地 Qwen3。4 号屏仍需升级；409、503 等失败应轻提示并继续手机原语音流程。
5. 日志筛选标签 SpeechInterrupt，可取得 target、requestId 和结果。202/DISPATCHED 仅为中控下发确认，实际声音仍需现场确认。
